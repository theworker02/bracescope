# bracescope

Brace HTML/Markdown scope fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/bracescope/

## Install / run

```bash
git clone https://github.com/theworker02/bracescope.git
cd bracescope
node src/cli.js
node --test
```
